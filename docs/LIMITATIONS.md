# Limitations & known issues

Every limitation or issue since P0, big or small. **Rules:** this file is updated after every step; rows are never deleted. A fixed row becomes `SOLVED in P<n>`. Status is one of `OPEN`, `ACCEPTED` or `SOLVED in P<n>` (a short note in brackets may follow). `tests/limitations.test.js` checks the format.

Sources: `docs/security.md` (limitations, risk register R1–R5, finding F1), `docs/PLAN.md` §12, the README progress log, and the QA of each step.

Last updated: P13, README rewrite and the extra-credit audit (21-Nov-2026).
