# Byte Island town: how it is built

All assets are generated by Python scripts in Blender 5.2.3. Nothing is downloaded, and no base meshes or AI 3D generators are used.

| Step | Script | What it does |
|---|---|---|
| 1. Model | `kit.py` | Builds the procedural town: 7 false-front buildings, the station, the bounty board, the dock with a rowboat, the lighthouse and keeper's hut, mesas, dunes, props, bunting and telegraph wires. Run with `--night` for the lantern-lit variant and `--no-render` to skip the preview renders. |
| 2. Bake | `bake.py` | Joins each building or prop group, unwraps it into one UV atlas, and bakes the procedural albedo × ambient occlusion into a JPEG atlas (1–2k). Lighting stays real-time in three.js, so one bake serves day and night. |
| 3. Export | `export_town.py` | Exports the GLB and `town.json` (landmarks, Y-up). Emissive materials (`Window_Warm`, `Lantern`, `Gold`) and ground or sea materials stay separate, so the engine can drive bloom, flicker and shaders. |
| 4. Optimise | gltf-transform 4.5 | `dedup → weld → webp (q82) → draco`. The size goes from 19.1 MB to 3.9 MB. (The pip build of Blender ships without the Draco library, so compression is done afterwards.) |
| 5. Verify | `verify_glb.py`, `viewrender.py` | Re-imports the GLB into an empty scene and renders it, to check what the browser receives. |
