## The problem
KnoDesk is Axisero's AI-powered WhatsApp front-desk chatbot and lightweight CRM for small businesses. Its replies were generic — it couldn't answer from each business's own information.

## What I built
I built KnoDesk's RAG (retrieval-augmented generation) knowledge-base pipeline, so the assistant answers from each business's own documents instead of giving generic replies.

## How it shipped
It went to a live, multi-tenant production system through an isolated feature branch, with zero disruption to the chatbot already serving customers.

## Result
The pipeline is live and serving 10+ businesses.
